# Why this has no front end

The operator asks for a capture, a review or a handover. The agent executes the CLI against the database and returns the result. Three branded HTML dashboards show the current week, quality queue and source permissions without a running web server.

A screen provides point-and-click selector creation, mobile access, visual previews and simultaneous editing. This base provides none of those. It uses a trusted operator, explicit recipes and read-only outputs. It does not provide offline browser capture or drag-and-drop editing. A permitted static website remains the input, not a new front end we build.

Use `/new-view` to add a read-only dashboard. Use `/customise` to change a field or operating rule with a reviewed migration. Enterprise DNA can build a team screen or additional collection method as part of a customised version, after the actual workflow has been scoped.
